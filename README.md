# ✅ MyTasks: Todo List Application

A simple and beautiful Todo List application built using Next.js, React, TypeScript, and Tailwind CSS.

MyTasks helps users create, manage, filter, and complete daily tasks through a modern glassmorphism-inspired interface with a green-themed design.

---

## 🚀 Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑 Delete tasks
* 🔍 Filter tasks by All, Active, and Completed
* 📊 View total, active, and completed task counts
* 🎨 Modern glassmorphism UI
* 🌿 Green and emerald-themed design
* 🧭 Responsive navbar and footer
* 📖 About page
* 📩 Contact page
* 📱 Mobile-friendly layout
* ⚡ Fast and responsive Next.js application

## ⚙️ Installation

## 1. Clone Repository

```bash
git clone https://github.com/Zainabar24/to-do-list-app.git
```

---

### 2. Navigate to Project Directory

```bash
cd to-do-list-app
```

---

### 3. Install Dependencies

```bash
npm install
```

---

### 4. Run Development Server

```bash
npm run dev
```

Open the application in your browser:

```text
http://localhost:3000
```

## 🧠 Application Workflow

1. Enter a task in the input field.
2. Click the **Add Task** button.
3. View the task in the task list.
4. Mark the task as completed using the checkbox.
5. Delete tasks when they are no longer needed.
6. Filter tasks by:
   * All
   * Active
   * Completed
7. View updated task statistics.

---

## 📊 Task Management Logic

### Add Task

New tasks are created with:

* A unique ID
* A title
* A default completed status of `false`

### Complete Task

Users can toggle a task between active and completed states.

### Delete Task

Users can remove a task from the list.

### Filter Tasks

The task list can be filtered according to its current status.
